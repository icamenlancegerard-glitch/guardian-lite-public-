# The Guardian — Independent Security Review

The Guardian invites rigorous, evidence-based scrutiny of its authorization-boundary design. This program is separate from Guardian Lite, whose documentation portal hosts this page.

**Reviewer starting point:** [Independent Testing Package](independent-testing/README.md)

The package includes:
- Review scope and trust boundaries
- Rules of engagement for safe, authorized testing
- Adversarial test plan
- Security finding template
- Readiness and evidence register

**Current status:** Documentation handoff prepared. A self-contained runnable sandbox and verified test release are not currently supplied by this public repository. Do not interpret this page as an open authorization to test production systems or as a claim that the implementation has passed independent review.

The public repository is a documentation and coordination portal. The Guardian implementation is maintained separately. Access to implementation artifacts and any technical test environment must be explicitly arranged with the project owner.

Start here: [independent-testing/README.md](independent-testing/README.md).
