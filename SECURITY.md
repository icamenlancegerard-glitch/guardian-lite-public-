# Security Policy

## Project status

Guardian Lite is an early-stage project. It is not represented as production-ready, independently audited, or certified.

This public repository contains documentation and high-level evidence summaries only. The implementation and detailed internal test materials are maintained separately.

## Reporting a security concern

Please do not publish credentials, tokens, private runtime configuration, personal data, or exploit details in a public issue.

Where GitHub private vulnerability reporting is enabled for this repository, use that channel. Otherwise, contact the repository maintainer through a private contact route listed on the maintainer's GitHub profile.

Please include, where safe:
- A concise description of the suspected issue.
- The affected component or documented boundary.
- The conditions needed to reproduce it.
- The observed impact.
- Any suggested containment steps.

Do not test against systems or data you do not own or have explicit permission to assess.

## Scope and response

There is no guaranteed response time or service-level agreement. A report may require additional information and validation before its severity or impact can be determined.

## Disclosure

Please allow the maintainer a reasonable opportunity to review a report before publicly disclosing details that could put users or systems at risk.
